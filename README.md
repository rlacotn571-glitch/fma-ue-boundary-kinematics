# Partial versus full performance in sensor-based Fugl-Meyer scoring

Analysis code and aggregate results for the manuscript:

> Kim C. Wearable kinematics detect whether, more than how fully, Fugl-Meyer upper-extremity movements are performed: an item-level analysis of 222 assessments in subacute stroke. *Submitted to Journal of NeuroEngineering and Rehabilitation.* [Update with the published citation.]

Archived code: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24488630.svg)](https://doi.org/10.5281/zenodo.24488630) (version 1.0.0; all versions: https://doi.org/10.5281/zenodo.24488629)

The study is a secondary analysis of the public REHAB dataset (Lv et al., Sci Data 2026;13:1136, https://doi.org/10.1038/s41597-026-07802-2). For each of 27 FMA-UE items it measures how well wearable kinematics separate the two score boundaries, 0 versus 1 (whether a movement occurs) and 1 versus 2 (whether it is complete).

## Contents

| Path | Contents |
|---|---|
| `analysis/` | All analysis scripts, final and superseded (numbered in the order they were written) |
| `results/final/` | Aggregate results reported in the manuscript |
| `results/superseded/` | Aggregate results of earlier analysis versions (see Additional file 1 of the manuscript) |
| `figures/` | Figures 1-4 (PDF and 300 dpi PNG) |

Assessment-level derived data (feature tables and per-assessment predictions) are not included until the redistribution terms of the REHAB dataset are confirmed. Every such file is regenerated by the scripts below from the original dataset.

## Data

Download REHAB from Science Data Bank via the Data availability statement of the data descriptor (link above) and extract it so that the folder `REHAB/Rehab_assessment/d01_raw_data/001 ... 222` and `REHAB/Rehab_assessment/Label.npy` exist. Two facts about the release matter for reuse:

- Gyroscope channels are in degrees per second, not radians per second as listed in the data descriptor.
- Folder order does not identify admission versus discharge assessments, and no patient identifiers are released.

## Environment

Python 3.12. Install the pinned packages with

```
pip install -r requirements.txt
```

Run every script with `python -I` (isolated mode). All random seeds are fixed, so results are reproducible.

## Reproducing the final results

Replace `<REHAB>` with the extracted `REHAB` folder and run from the repository root:

| Step | Command | Output |
|---|---|---|
| 1. Features | `python -I analysis/02_extract_features.py <REHAB> results/features_v1.csv` | Kinematic features per item-assessment |
| 2. Supporting analysis 1 (posture pairs) | `python -I analysis/14_v3.py <REHAB> results` | `v5_A_*` files |
| 3. Primary analysis (ordinal model, calibration, discordance) | `python -I analysis/16_v4.py results` | `v5_summary.txt`, `v5_B_*`, `v5_H3*` |
| 4. Missing data and per-item AUC CIs | `python -I analysis/20_tripod_support.py results` | `v5_B_item_auc_ci.csv` |
| 5. Binary models, refit bootstrap, pooled accuracy, heterogeneity, determinants | `python -I analysis/22_v6.py results` | `v6_*` files |
| 6. Figures | `python -I analysis/17_figures_v4.py results figures` | Figures 1-4 |

Steps 2-5 take a few minutes each on a laptop. Scripts 19, 21 and 18 build the manuscript's additional files and manuscript document; script 18 needs the manuscript source, which is not part of this repository.

Scripts 00-13 and 15 are superseded exploratory versions kept for transparency. The changes between versions and their reasons are listed in Additional file 1 of the manuscript.
